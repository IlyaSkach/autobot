# Autobot — Telegram-бот для заявок на автомобиль

## Быстрый старт

1. Скопируйте файл `env.example` в `.env` и укажите параметры:
   ```
   BOT_TOKEN=ваш_токен_бота
   MANAGER_USERNAME=@SkIlyaA
   MANAGER_CHAT_ID=123456789
   ```
   `MANAGER_CHAT_ID` — числовой идентификатор менеджера (можно получить, переслав любое сообщение менеджера боту @userinfobot). Если указать и `MANAGER_CHAT_ID`, и `MANAGER_USERNAME`, приоритет будет у идентификатора.
2. Установите зависимости:
   ```
   npm install
   ```
3. Запустите бота:
   ```
   npm start
   ```

## Возможности

- Сбор информации о желаемом автомобиле, бюджете и городе доставки.
- Сбор контактных данных и предпочтительного канала связи.
- Раздел с описанием компании, вопросами и ответами.
- Возможность написать сообщение менеджеру.
- Отслеживание посетителей и заявок в JSON-файлах в папке `data`.

## Структура проекта

- `src/bot.js` — основной файл Telegram-бота.
- `src/storage.js` — утилиты для работы с локальным хранилищем.
- `data/requests.json` — сохраненные заявки.
- `data/messages.json` — сообщения менеджеру.
- `data/visitors.json` — информация о посетителях бота.
# AutoBot

Телеграм-бот для сбора заявок на подбор автомобиля.

## Возможности

- Сценарий сбора заявки с уточнением марки, модели, бюджета и города доставки
- Сбор контактных данных: имя, телефон, email, предпочтительный канал связи
- Разделы «О компании», «Вопросы и ответы» и «Написать менеджеру»
- Логирование всех обращений и посетителей в локальные JSON-файлы

## Быстрый старт

1. Скопируйте `.env.example` в `.env` и укажите токен бота:
   ```bash
   cp .env.example .env
   ```
2. Создайте и активируйте виртуальное окружение Python 3.10+
3. Установите зависимости:
   ```bash
   pip install -e .
   ```
4. Запустите бота:
   ```bash
   python -m autobot.main
   ```

При первом запуске будут автоматически созданы файлы `data/requests.json` и `data/visitors.json` для хранения информации.

## Структура данных

- `data/requests.json` — массив заявок на подбор авто
- `data/visitors.json` — журнал запусков/посещений, фиксирует данные пользователя и отметку времени

## Переменные окружения

- `BOT_TOKEN` — токен вашего Telegram-бота
- `ADMINS` — список `user_id` администраторов через запятую (опционально)
